# **Fires USA – Projet Datascientest**

## **Description**
Fires USA est une application interactive développée avec **Streamlit** pour analyser et visualiser les données historiques des feux de forêt aux États-Unis.  
Le projet inclut la **préparation des données**, l’**analyse exploratoire (EDA)**, et un **modèle de classification multiclasse** permettant de prédire la gravité des feux (petits, moyens, grands).

---

## **Fonctionnalités**
- Chargement et traitement des données Parquet avec **pandas**.  
- Analyse exploratoire et visualisation interactive des données.  
- Modèle de machine learning multiclasse pour prédire la gravité des feux.  
- Interface Streamlit pour explorer les données et visualiser les prédictions.
